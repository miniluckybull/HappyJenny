# HappyJenny：乔巴的星际大冒险

一款儿童向 3D 太阳系科普浏览器游戏。驾驶飞船探索八大行星，登陆星球寻找知识信标，通过问答收集知识旗帜，并发现幻想洞穴营地。

本项目为非官方同人科普游戏；行星大小与距离经过游戏化压缩，洞穴营地包含明确标注的冒险想象。

## 游戏内容

- **3D 星际航行**：手动驾驶飞船，或点击星球自动导航。
- **八大行星探索**：每颗星球设有三个知识信标，共 24 张知识卡。
- **登陆与扫描**：在地表移动、扫描并互动，学习后完成友好问答。
- **洞穴营地**：发现 8 座幻想营地，集齐 8 面知识旗帜。
- **完整游戏流程**：标题、探索、暂停、友好救援、毕业结算与继续探索。
- **学习日志**：随时查看行星资料、已解锁知识和洞穴科学说明。
- **桌面与移动端**：键盘、鼠标及屏幕触控操作，支持声音和画质设置。
- **本机进度**：知识卡、洞穴、旗帜与偏好保存在当前浏览器，不跨设备同步。

## 操作

### 太空驾驶

- `W`：加速。
- `S`：刹车。
- `A` / `D`：转向。
- `E`：着陆。
- 也可打开星球导航或点击三维星球自动航行。

### 地表与洞穴

- `WASD`：移动。
- `Q`：扫描。
- `E`：互动。
- `L`：返回太空。
- `Esc`：暂停或继续。
- 手机和平板可使用屏幕方向按钮与互动按钮。

## 本地运行

需要 Node.js 20 或兼容版本。

```bash
npm ci
npm run dev
```

类型检查与生产构建：

```bash
npm run check
npm run build
npm run preview
```

基础浏览器回归：

```bash
npm run verify
```

可通过 `CHROMIUM_PATH` 指定本机 Chromium，例如：

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run verify
```

## 技术与资源

- React、TypeScript、Vite、React Router、Three.js。
- 游戏场景和界面位于 `src/game/`、`src/pages/` 与 `src/index.css`。
- 飞船资源及其加载代码位于 `public/assets/shuttle/`，使用时请保持该目录完整。
- 随附 Three.js MIT 许可文本：`public/assets/shuttle/THREE-LICENSE.txt`。
- 进度使用浏览器 `localStorage`；清除浏览器数据会删除记录。
